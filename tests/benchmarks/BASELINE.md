# Baseline benchmark (SC-007, TST-003-036)

Recorded for P2 (core architecture). Budgets are not enforced here; P9 sets and enforces them.

## Machine

| | |
|---|---|
| CPU | 13th Gen Intel Core i5-13420H (12 logical cores) |
| Memory | 15.6 GiB |
| OS | Linux 7.0.0-42-generic |
| Python | 3.12.3 (system interpreter) |
| Storage | local SSD (`fsync` enabled for customer writes) |

## Workload

300 generated modules, 30 files each (models, views, JavaScript, ACL, manifest), 9 000 files,
generated by `tests/benchmarks/generate_repo.py` with seed `20260106`. Source version 14.0,
target 19.0. Wall time from `subprocess` start to exit; peak RSS of the child process
(`ru_maxrss`).

Reproduce:

```bash
python tests/benchmarks/generate_repo.py /tmp/bench/repo 300
python tests/benchmarks/bench_analyze.py /tmp/bench/repo
ODOOFLUX_BENCH=1 python -m unittest discover -s tests/benchmarks -t tests -p "test_bench_opt_in.py"
```

## Results

| Run | Implementation | Wall time (s) | Peak RSS (MiB) |
|---|---|---|---|
| analysis (3 runs) | P2 core (`odooflux.py`) | 1.10, 1.07, 1.07 | 40.7–41.0 |
| analysis (3 runs) | P0 legacy script | 0.69, 0.69, 0.69 | 30.8 |
| fix, `--backup` (1 run) | P0 legacy script | 7.22 | 31.3 |
| fix (2 runs) | P2 core | 16.68, 16.70 | 39.4–39.7 |

P1-style single fixture (Appendix A, 10 runs average): P2 core 89 ms, P0 legacy 80 ms (+11 %).
The plan goal of at most 20 % slower applies to the fixture set and is met.

## Where the time goes

- Analysis: the rule regexes (identical work to the legacy script) take most of the time. The
  remaining overhead is per-file object creation, the engine's step runner, and report
  serialisation.
- Fix: a verified backup (copy and two digests), a full workspace copy (FR-012), and an `fsync`
  per promoted file and per run-log entry (FR-006). These are the safety guarantees the spec
  requires. They cost about 2.3× the legacy fix time on this workload.

Open for P9: decide whether the workspace can avoid a full copy, and whether the run-log `fsync`
can be batched without weakening the per-entry guarantee.
